# Dataset contract

No newly collected webcam or QOLDA-glove participant dataset ships with this repository. Release 0.3 includes derived results from the attributed public UCI405 dataset; its raw CSV is downloaded by the benchmark script. See README for source, ID discrepancy and split protocol.

`qolda-vision.dataset.v1` is the JSON format generated by **Save dataset JSON**. Its `rows` array contains:

| Field | Constraint | Meaning |
| --- | --- | --- |
| `time` | Finite number >= 0 | Capture timestamp in milliseconds; relative to the browser's time origin |
| `source` | `camera` | Provenance required for learning |
| `group` | 1–80 letters, digits, hyphens or underscores | Independent recording-session identifier |
| `label` | One of the four supported labels | User-assigned ground truth |
| `vector` | Exactly six finite numbers in [0,1] | Five extension features and scaled pinch feature |

The validator discards unknown row properties and returns fresh feature arrays. It rejects synthetic rows, unsupported schema versions, malformed IDs, unknown classes, out-of-range values and datasets outside 1–3,000 rows. Browser/JSON CLI imports also enforce a 2 MB file-size limit.

Collect only with permission. Do not put names, patient records or private video in the repository. Session IDs are not automatically person IDs. To claim subject-independent evaluation, all recordings for a participant must share one held-out group. Record collection choices using `EXPERIMENT.md`.

CSV exists for interoperability; JSON is the recommended validated roundtrip format. A CSV exported from the movement studio has baseline-generated labels and is **not** the ground-truth gesture dataset. Use the Gesture learning export for evaluation.
